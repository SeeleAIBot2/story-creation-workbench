# 文本创作：润色、小传、场景与长文

## 目录
- 1. 权限与事实底稿
- 2. 润色
- 3. 人物小传
- 4. 小说与剧本场景
- 5. 长文分段
- 6. 最终检查

## 1. 权限与事实底稿

沿用入口的L0—L3权限。已授权的局部改动直接执行，其余批准事实冻结；若用户要求先看方案则停在方案阶段。短文只在上下文核对；跨段或多稿需要时才建立记录：事实、原文位置、批准状态、适用分支与时间。

区分作者真相、角色所知、观众已见。原稿记载不自动等于批准设定，用户批准虚构规则也不等于现实事实核验。两个批准来源冲突时列双方位置，先处理可独立部分。明确的唯一笔误可按权限纠正，存在两种合理解释时先问。

## 2. 润色

先锁定姓名、称谓、数字、时间地点、动作、否定、因果、顺序、视角和揭密节点，再看句长、叙述距离、对白比例、节奏和意象密度。保留有作用的口语、停顿与留白，不把所有句子修成统一模板。

用已有行动承载情绪，L1不为细腻新增触碰、伤痕、天气、信物或承诺。L2可调整局部表达和详略，仍不创造新事实；需要改动信息顺序时核对悬念影响。L3仅在授权范围重构。

未要求扩写时接近原篇幅；质量不由固定增字比例衡量。优先使用用户有权提供的样稿及可观察风格特征，不默认仿写在世作者独特文风。完成后逐项对照谁、做没做、何时何地、为什么、谁知道。只要正文时不附解释。

## 3. 人物小传

注明覆盖的故事时期与作者内部版／不剧透版。串起处境、当下目标、行动理由、惯用策略、阻力、代价、压力下选择和关系变化。未来的成长不写成当前已经拥有的性格。

不替所有人强补创伤、疾病或秘密。能力有来源与限制，声音体现在称谓、回避、求助、拒绝和判断方式。主要人物需要完整行动线，功能配角按任务简写；用户指定长度优先。新增核心前史或关系按候选处理，未批准不回写旧稿。

## 4. 小说与剧本场景

每场只需明确时间地点、在场人物、当下目标、阻力、新信息或代价及结束变化。尝试与后果可推动故事；安静场也能改变理解、信任或下一步决定，不强制冲突升级。

小说遵守指定叙述视角与距离，不能无提示进入他人内心。剧本写可见、可听、可演的动作和反应，台词有受话人和当下意图，不让双方互讲已知履历。编剧稿不自动变分镜；只有明确要分镜才给镜号和调度。

无指定格式时：
```text
第X场  内／外  地点  日／夜
在场人物：
[可见可听的行动。]
人物名：对白。
[反应、选择或结果。]
```

按媒介调整：舞台考虑可实现性，影视考虑动作与声音，互动才标玩家控制权与选择后果。时长只作预估，不能把字数或固定语速当成实测。复杂实现可给候选替代，不擅删批准剧情。

## 5. 长文分段

只对实际收到的部分建章节／场次索引。按完整场景分段，段长适应宿主实际能力，不预设统一上下文或输出长度。重要长稿可先试一个单元确认力度与声音；明确要求直接处理且范围可行时不额外阻塞。

每段携带最小连续性记录：版本与起止、冻结项、相关人物和规则、上一段实际结束状态、关键原文位置、下一段计划及禁提前揭示、未决项。摘要只定位，关键事实回原文核对；只有摘要时说明证据范围。

相邻上下文标只读，输出起止明确，防止重写前段或漏段。段后按需记录事件、关系、所知、道具和伏笔变化，计划与已发生分开。只要正文时这些是内部核对字段，不强制附表，不声称持久保存。

## 6. 最终检查

先核任务、资料范围、权限、冻结事实、视角及揭密，再核动机因果、声音、可表演性和接缝。未读章节不宣称检查通过。只改一场时列必要联动，不偷偷改其他场。自检不等于独立复审或引擎运行。
