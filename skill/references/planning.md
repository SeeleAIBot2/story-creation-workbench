# 策划与题材卡边界

## 1. 调用题材库

从全量标签索引选择主类型，再按需叠加分支、机制、情节关系、人设、背景、关系结构和基调。相同词在不同层级出现时保留各自归位，不合并为新的主类型。待澄清标签只作备注，明确含义前不转成生成约束。版权来源独立核权，不能用替换名字绕过改编权限。

v1.1收录标签、通用流程及[23张女频短剧题材知识卡](female-short-drama.md)。按主类型同号读取目标卡，借其吸引力、动力与关注点深化人物目标、事件与代价；机制、关系、背景和基调按该参考第四节分层。卡片为知识整理与创作建议，未做创作效果实测，市场、文献与平台判断按其使用等级处理。不自动从标签批量生成题材卡；本次授权内的新故事候选不自动进入通用库。

## 2. 深化已选方向

用户选定方向后，补足双方具体目标、失败损失、相互需要、可触发场景的规则、升级与兑现。每个重要转折写清：谁看到什么→如何解释→作出什么选择→产生什么代价或关系变化。不机械规定每集必须反转或固定付费点。

局部修改冻结其余设定；换一批时保留已确认目标与限制，改变事件机制。选定一个方向不等于批准其中所有新设定。策划只做到本轮要求层级，不自动生成全剧。

## 3. 按需交接

```text
稿件与候选版本／当前范围／批准状态：
一句话故事与核心体验：
双方目标、代价、相互需要与冲突：
规则→触发事件→选择与代价→局面或关系变化：
升级、关键转折、阶段兑现：
冻结项／授权变更／待决定：
后续范围／禁止提前揭示：
实际使用的题材标签／外部事实待核：
```

只交已经形成的结论，计划与已发生事件分开。用户只要正文时不附策划卡。创作建议不冒充市场证据或平台规范。

## 4. 人工题材卡的最小规范

新增或修订人工卡时记录标签原名与层级、适用范围、核心体验、人物动力、事件机制、可变方向、创作边界、来源与使用权限、版本及试用记录。区分硬边界、建议与套路提醒；未经授权的外部卡不复制进库。本包女频知识卡状态为“已整理／待试用”；新增卡先标“待审阅／待试用”，实际测试后再更新，不用主类型数量推算具体卡片覆盖。来源与权限未完整核验的部分保留待核，不将知识卡收录解释为素材再许可。
