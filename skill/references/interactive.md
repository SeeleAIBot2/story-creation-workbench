# 互动：控制权、状态与分支

## 1. 明确互动合同

仅在明确要求角色扮演、角色卡、世界书、互动续接、测试或分支时使用。确认模型控制哪些角色和环境、玩家控制什么，以及当前节点与内容边界。资料够就续写，不为填表阻塞。

模型控制约定角色的行动和环境后果，玩家控制自己的台词、内心、同意和重大选择。对玩家可写可观察处境，不预设其爱慕、恐惧、答应或完成行动。NPC可以拒绝、误会或有目标，但不能绕过作者层暂停、改写、跳过与退出。

## 2. 角色卡与世界书

角色卡保留当前时期的身份、目标、策略、能力边界、声音、关系、所知与未知。秘密的作者真相与角色当前认知分开，不靠一条人设标签决定全部行为。

世界书每条写一个事实或机制，带来源与批准状态、适用时间和分支、知情与可见范围、召回条件及冲突待核。召回供模型参考不等于NPC知道，作者资料不可因进入上下文就写进角色台词。宿主不能可靠隔离秘密时，玩家可见包不带幕后文本。

## 3. 一拍续写

承接上轮实际结束状态，推进一个可回应的行动单元，留下玩家空间；默认不附选项、数值、面板或审校表。玩家输入不必总是选预设项，合理的自由行动按规则响应。

状态只追踪有用事实：位置时间、身体和资源、关系与承诺、知情、物品、未决行动。数值只有用户或引擎要求时使用。摘要记录可见事件和必要作者事实，不导出隐藏推理，不声称自动永久记忆。

## 4. 分支与回接

明确选项的实际差异、适用条件、即时后果、延迟影响及是否回收主线。不能把不同文案但完全同一后果声称有实质分支。允许轻量风味选择，但标明其作用。

分支隔离事件、关系与秘密；合流时核对两侧可共有的状态，不能让未发生事件进入另一分支。玩家撤回或作者改写时建立新候选状态，不悄悄保留旧结果。尚未实现的分支标“设计候选”。

## 5. 测试与现实边界

角色探针独立于正式剧情。记录实际输入与输出，检查越权代写、泄密、规则漂移、串分支和状态丢失；未执行不能说测试通过。

遵守宿主内容规则，尤其涉及年龄、同意和权力差异时。不把虚构互动包装成现实权威、治疗或真实人际关系，不用排他、威胁或内疚维持现实依赖。跨产品不假定账号、记忆或隐私权限共享。
