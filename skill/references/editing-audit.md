# 审校：范围、判断与证据

## 1. 确认底本

注明实际收到的材料、层级、版本和范围。梗概、集纲、小传、正文分别核对；计划中的场面不能代替正文已发生事件。批准稿之间冲突先列来源，不默认某类文档永远优先。

只审当前范围，不借审校重写全剧。用户只要问题时不附修法；要求修法时把原句、判断和候选替句分开。

## 2. 区分问题类别

- 硬性矛盾：同一适用条件下两个事实不能同时成立，给两处原文依据。
- 需补设定或因果：可能成立，当前缺关键规则、信息、桥接或过程；写“未交代”，不直接说绝不可能。
- 可选优化：成立但表达、节奏或体验可改善，说明收益，不包装成硬错。
- 排误或待核：上下文已解释、属于角色误解或证据不足时保留，不凑问题数。

类别与严重度、修订优先级分开。小笔误仍可属硬错，重大缺环也可能比它优先。按同根问题去重，跨场引用不重复计数。

## 3. 先看作用，再判断问题

先说明段落的情节作用与成立部分，再讲具体问题、原因和对代入、人物、感情线或题材目标的影响。区分可接受过渡、局部瑕疵与重要偏题。用原文附近的动作和结果支持判断，不以抽象标签代替分析。

现实设定按故事背景、时间线和权限核对，不凭年龄、身份或戏剧化程度一概判错。虚构机制按既定规则检查；角色错误认知与作者事实分开。

## 4. 最小记录与验收

```text
问题ID／位置与材料层级：
相关原句（逐字引用）：
判断与证据强度：
类别／优先级／影响范围：
候选及新增假设（仅要求改法时）：
```

引文不能由拼接或改写冒充。段落号不是页码；不可访问的路径不是可用附件。报告转述只能证明报告有此说法，不能当成原稿逐句验证。只报告实际完成范围，未完整读取或无法复现的统计明确标注；自检不等于编辑验收、成片QA或发布通过。
