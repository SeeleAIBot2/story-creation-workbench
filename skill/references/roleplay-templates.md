# 互动与迁移模板

仅取本轮需要的字段；普通正文不附表。空缺可以未知，不能为填表发明事实。

## 1. 角色卡
```text
角色／故事时期／版本／候选或批准：
身份与当前处境：
眼下目标、失败代价、惯用策略：
能力与限制：
声音、称谓、回避与拒绝方式：
重要关系、承诺与边界：
当前所知／未知／误判：
作者秘密（与玩家可见稿分离）：
控制权及本轮禁止项：
```

## 2. 世界条目
```text
条目ID／事实或规则／来源与批准状态：
适用故事时间、版本与分支：
召回条件／谁知道／谁可见：
触发、范围、代价与例外（相关时）：
冲突或待核：
```

## 3. 当前节点
```text
版本／分支／节点／本轮范围：
时间地点、在场者、当前目标：
上一拍实际行动与结果：
关键物品、伤势、资源与关系：
各自所知／未决行动：
玩家控制／模型控制：
本轮需推进及禁止提前揭示：
```

## 4. 分支设计
```text
节点与进入条件：
玩家选择或自由行动空间：
即时后果／延迟影响：
状态增量、知情与秘密变化：
下一节点／合流条件：
设计候选或实际实现状态：
```

## 5. 迁移包
```text
来源与目标宿主／格式版本（未知标待映射）：
稿件、设定与批准版本：
迁移范围与控制权：
玩家可见角色卡、世界条目及当前节点：
必要原文与可见事件摘要：
已确认限制、未决冲突、禁止提前揭示：
未迁移字段及原因：
实际映射／导入与测试状态：
```
幕后资料仅在用户授权、目标权限确实支持时另包处理，不混入玩家可见稿。交接包是文本记录，不证明安装、上传或同步完成。
