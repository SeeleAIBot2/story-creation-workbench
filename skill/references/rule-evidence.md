# 规则与证据

## 1. 只核驱动当前戏的规则

按需确认规则来源与批准状态、适用对象、触发条件、权限、范围、代价、持续、失效、恢复、表现和例外。普通对话不强填全参数；能力、系统、怪谈或技术主导行动时再展开。

幻想规则可以超现实，但在同一作品内保持一致。新能力不能只在主角需要时免费出现；规则变动需有作品允许的事件和后果。角色对规则的猜测与作者底层机制分开，不能用事后新增条款惩罚此前合理行动。

## 2. 信息传递与秘密

记录事实是什么、谁最早知道、通过什么获得、是否可靠、谁看见传递，以及观众何时获知。读心、预知和回忆各有方向、范围与误差，不自动把单向信息升级为全知。

旁白真相不等于角色已知；听到猜想不等于内容属实；观察结果不自动证明原因。重复公开秘密时说明新的知情者或新事实，不把已经公开的内容反复当首次揭示。

## 3. 推理与证据强度

拆开观察、推断、传闻、角色主张和已证实事实。线索应足以支撑当前结论，允许保留多个解释。关键解法所依赖的条件应提前出现或有公平的获取过程，不能到揭晓时才补决定性信息。

证据按来源、取得方式、原件或副本、保管和转交记录。内容一致、内容真实、取得合法和足以证明某事是不同问题；单一校验或角色权威不能包办全部。

## 4. 专业与现实事实

法律、医疗、历史、科技和职业机制只在影响本轮因果或现实可行性承诺时核权威资料。未核就指出具体问题和适用背景，不虚构查证过程。架空制度、角色违法或错误判断可在故事中成立，但叙述不得把待核现实结论写成已证实。

专业修法若新增关键制度、金额、权限或能力，按修改权限作为候选；只评不改时说明缺环，不擅定新规则。
