# 选题：从概念到可展开的故事

## 1. 选择入口

原创从现有概念与限制建立故事；改写先确认实际收到的原作范围与授权；优化先保留有效部分；短评只判断当前文本。只给标题时可提出假设方向，不编造原作内容。

未指定时给3个实质不同方向。区别应落在人物目标、阻碍、资源、代价、关键选择或解决机制上；只换姓名、职业和场景不算新方向。比较方向时说明各自承诺的核心体验，不臆测市场热度。

## 2. 把吸引力变成事件

- 主角现在要得到或保住什么，为什么今天必须行动？
- 什么人或规则阻止行动；对方自己的目标是什么？
- 主角的尝试怎样改变局势、提高下一次选择的成本？
- 关键关系中双方各提供什么、各承担什么；关系变化能否在行动里看见？
- 结局或阶段目标是否兑现开场承诺，是否依赖突然出现的资源？

女频短剧需要题材抓手时，按[题材标签索引](genre-taxonomy.md)01—23编号读取[女频短剧题材知识](female-short-drama.md)中的目标卡及必要标签层级，将吸引力与动力落实为以下行动链；混合题材注明主次。卡片与灵感模板为可选参考，不增加默认附件，不把市场假设或来源编辑偏好升级为硬规则。

有标签不等于有故事。先选主类归档，再用分支、机制、情节关系、人设、背景与基调解释具体事件；不强制堆满标签。选择幻想题材时保留其特色，再检查内部规则与视觉制作难点，不以真人拍摄成本一刀切删除。

## 3. 跨时代、地区与职业适配

改动一项就核对相关链条：身份或规则→信息来源→动机→关系和权限→可采取的行动→证据与结果。行业、制度、财务或专业知识只在实际相关处核验；未知的现实主张不包装成定论。保持感情线与主线之间的作用，不让新的职业说明挤掉原本承诺的体验。

## 4. 输出与短评

无指定格式时，每方向给标题、一句话选题、核心关系、约200—350字梗概和独有看点。梗概写到关键选择的后果，不只停在“必须作出决定”。只要梗概时省掉其他字段；不自动生成全集大纲。

短评默认3—6条，每条给具体判断及文本依据或业务影响；明显问题少就少写。只要缺点时不附优点、改法或新策划。可以肯定有效构思，但不以个人偏好否定题材。优先修关键因果、方向重复、核心体验缺失，再整理措辞；只评不改和超出授权部分不实际修订。
