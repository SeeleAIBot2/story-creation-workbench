# 连续性：版本、时间、人物与物品

## 1. 装配与接缝

只在长文、跨集或具体疑点时建表，普通单句不建全剧工程。锁定执行底本，重编号保留旧号到新号映射。逐接缝核对上一场末与本场初：时间地点、在场者、危机、已知信息、身体与资源、关系和下一步目标。

倒叙、回顾、循环或跨集接拍可以使用，标清时间与回接点。重复事件若有新对象、新证据或新代价，应在文本中可辨；不能每场把人物重置为第一次获知。未读部分不得脑补已发生桥接。

## 2. 时间与空间

对相关期限记录起算事件、截止、对象、当前剩余时间和改变期限的事件。连续动作与场头日夜、相对时间词相互核对；并行场不必依集数逐日推进。

人物按场初位置→进出与移动→场末位置追踪。名单不等于某一时点全部在场；营救、追踪和消息传递需有足够定位、路线、时间和知情依据。特殊空间遵守作品机制，不替缺失规则补设定。

## 3. 物品、状态与限制

关键物用最小记录：物品ID、形制数量、持有人和位置、交接或消耗事件、当前状态。普通随身携带不必每次演出；涉及唯一性、毁损、封存、关键证据或争夺时桥接需可辨。

伤势、资源、权限、禁令和关系不能无事件恢复。物品本体与使用权限分开，原件、副本、样本与影像分开；修复、补货、调取或替换需足够来源。画外或省略动作可以合理承接，不能用省略掩盖决定性矛盾。

## 4. 制作与交接

地点、内外与日夜转换按媒介另起场。人物能看到、听到什么与观众画面分开。动作按职责、所知和风险区分，避免所有人统一反应。

复杂调度可建议更清楚的候选，保留原剧情目标。可拍性或视觉制作意见只是设计判断，未拍摄或运行不称安全执行、成片验收或引擎测试通过。
