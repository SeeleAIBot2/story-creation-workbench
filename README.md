# 故事创作工作台

运行入口：https://seeleaibot2.github.io/story-creation-workbench/

本地交互工作台，知识版本 v1.2。无后端、无模型接口、无密钥，无正文上传。

## 可用模块

- 任务、L0–L3 修改力度、范围、版本、冻结项、交付要求。
- 可搜索选取的 23 张女频题材卡与 496 项分层归位标签（同名跨层保留），方向候选与策划深化。
- 人物编辑、原始重名和一字近似提示、本地组合候选、全项目改名预览及快照恢复。
- 原稿／候选稿双工作区，审稿、连续性、规则证据、互动分支、文本交接和验证记录。
- 当前浏览器自动保存、多个项目、最近 8 个快照、JSON 导入导出、文字复制及 MD/TXT 导出。
- 按任务整理执行指令、手动粘贴模型结果。**本站未连接模型，不自动创作或验证剧情。**
- 16 份公开知识原文与按任务关联的参考。原 `skill/`、独立 `name-editor.html` 与 ZIP 均保留。

## 数据与边界

内容只存本机浏览器 localStorage；没有账号或跨设备同步。清理浏览器会丢失数据，请定期导出 JSON。共用设备可读取本地资料。导入作为新项目保留旧项目。完整 JSON/MD 包含作者资料；玩家可见交接包需单独导出，并人工复核字段中的剧透。复制到外部模型由使用者自行决定。

命名检查仅针对已登记姓名和别名。近似为 Unicode 字符编辑距离 1，不查拼音、谐音或全网唯一性。统一改名是精确子串替换，请核对预览；应用会改变原稿并自动保存改名前快照。项目角色库可导出为 v2 JSON 后在现有名字工具中导入；两者不自动共享数据。

## 本地检查

无需构建或安装网页依赖。静态托管此目录即可。

```sh
python3 scripts/build-knowledge.py
node --check assets/core.js
node --check assets/app.js
node --check assets/knowledge.js
node --test tests/core.test.cjs
```

知识包从现有公开文档确定性生成，不包含私人样式参考源。UI 的暖灰白、宋体标题和三栏布局为独立重写，无原私信、原脚本、密码或品牌素材。

本次验收的浏览器 CDP 导航超时，未完成真实浏览器渲染与移动端视觉验收。纯 JS 逻辑和 JSDOM 集成验证已覆盖编辑、筛选、保存恢复、导入导出、改名和回填；剪贴板／下载交付在集成环境中模拟，响应式布局以 CSS 静态检查为限。没有进行真实模型生成或引擎运行测试。

集成测试脚本：`tests/dom.integration.cjs`。在隔离测试目录安装 `jsdom` 后，用 `NODE_PATH=<该目录>/node_modules node tests/dom.integration.cjs` 运行。网页运行不依赖 jsdom。
